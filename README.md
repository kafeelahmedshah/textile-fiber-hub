# 🧵 Textile Fiber Hub

A Streamlit web application for learning and revising textile fibers.

## Features

- Fiber library and search
- Natural and man-made fiber classification
- Source and composition
- Microstructure and macrostructure
- Properties and common uses
- Fiber comparison
- Multiple-choice quiz
- Short exam notes

## Project Files

```text
textile-fiber-hub/
├── app.py
├── requirements.txt
└── README.md
```

## Run Locally

```bash
git clone https://github.com/YOUR-USERNAME/textile-fiber-hub.git
cd textile-fiber-hub
pip install -r requirements.txt
streamlit run app.py
```

## GitHub

Create a repository named `textile-fiber-hub` and upload the three files.

## Streamlit Deployment

Connect the GitHub repository to Streamlit Community Cloud, select `app.py` as the main file, and deploy.
